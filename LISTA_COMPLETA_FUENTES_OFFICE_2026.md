## ⚙️ INSTALACIÓN Y USO

### En Excel (ExcelJS)
```typescript
import { EXCEL_FONTS } from '@/utils/excelGenerate/utils/excelTools';

applyAdvancedFontStyle({
  row: worksheet.getRow(1),
  startCol: 1,
  endCol: 5,
  fontName: 'Calibri',  // Selecciona de EXCEL_FONTS
  fontSize: 12,
  bold: true
});
```

### En HTML/Email
```typescript
import { HTML_FONTS } from '@/utils/htmlString';

const style = new HtmlStyleBuilder()
  .setFont('Times New Roman')  // Selecciona de HTML_FONTS
  .setFontSize(14)
  .build();
```

### En PDF
```typescript
import { PDF_STANDARD_FONTS } from '@/utils/generateFile';

const font = await pdfDoc.embedFont(
  PDF_STANDARD_FONTS['Times-Bold']  // PDF tiene 12 nativas
);
```

## 📝 NOTAS IMPORTANTES

1. **PDF limitado**: Solo 12 fuentes estándar (Helvetica, Times, Courier con variantes)
2. **Web-safe**: Las fuentes más comunes funcionan en todos los navegadores
3. **Office 2026**: Aptos reemplaza a Calibri como predeterminada
4. **Compatibilidad**: No todas las fuentes están disponibles en todos los sistemas
5. **Fallback**: Siempre incluir familia genérica (serif, sans-serif, monospace, cursive)
