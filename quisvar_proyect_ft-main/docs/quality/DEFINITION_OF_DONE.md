# Definition of Done

Un ítem solo está terminado cuando:

1. Cumple el campo de acción de la matriz.
2. El control no se habilita sin acción real.
3. Tiene prueba funcional automatizada.
4. Tiene evidencia visual identificada.
5. No introduce clipping, superposición o scroll horizontal global.
6. Es operable por teclado y tiene nombre accesible.
7. Respeta temas y reduced motion.
8. Persiste correctamente cuando corresponde.
9. Build y pruebas relevantes pasan.
10. Consola y red no presentan errores inesperados.
11. La documentación y matriz reflejan el estado real.

Puertas que hacen fallar la iteración: build roto, prueba fallida, excepción no controlada, 4xx/5xx inesperado, icono ausente, acción ficticia, pérdida de contenido, amarillo injustificado, clipping, scroll global, regresión de edición/deshacer/guardar o violación grave de accesibilidad.
