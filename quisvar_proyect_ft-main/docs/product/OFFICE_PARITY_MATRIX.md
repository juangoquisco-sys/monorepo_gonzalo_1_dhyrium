# Matriz de paridad — Dhyrium Writer

> **Vigencia REV-33–35 (11 de agosto de 2026).** El motor canónico es el editor web independiente de Dhyrium. Microsoft Word, Word Desktop, Office, WebDAV y `ms-word:` quedan únicamente como referencias históricas o visuales y no forman parte del flujo editorial canónico. Las secciones antiguas que los describen se conservan para trazabilidad, pero están **sustituidas** y no autorizan implementación.

Estados permitidos: `pendiente`, `parcial`, `funcional`, `verificado`. `Verificado` exige prueba funcional y captura identificada.
