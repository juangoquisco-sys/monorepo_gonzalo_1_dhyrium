# Manual de usuario de Dhyrium

Version: Junio 2026

## 1. Proposito del manual

Este manual explica el uso general de Dhyrium para usuarios operativos. Su objetivo es guiar los flujos mas comunes: iniciar sesion, navegar por el sistema, revisar tareas, registrar tramites, consultar asistencia y usar los modulos disponibles segun permisos.

La plataforma muestra u oculta opciones segun el rol asignado. Si una seccion de este manual no aparece en tu cuenta, solicita al administrador que revise tus permisos.

## 2. Acceso al sistema

### Iniciar sesion

1. Abre la URL del sistema en tu navegador.
2. Ingresa tu usuario y contrasena.
3. Presiona el boton de ingreso.
4. Si los datos son correctos, el sistema abrira la pagina de inicio.

### Recuperar contrasena

1. En la pantalla de login, usa la opcion de recuperacion si esta disponible.
2. Sigue el enlace enviado por el sistema.
3. Registra una nueva contrasena.
4. Vuelve a iniciar sesion con tus credenciales actualizadas.

### Cerrar sesion

1. En la barra lateral, abre el menu de usuario con tu avatar.
2. Selecciona Salir.
3. El sistema cerrara tu sesion y limpiara la informacion local.

## 3. Navegacion principal

### Barra lateral

La barra lateral contiene los modulos principales habilitados para tu rol. Cada icono representa una area del sistema. Al pasar el cursor por un icono, se muestra el nombre del modulo.

En pantallas pequenas, usa el boton de menu para abrir o cerrar la barra lateral.

### Menu de ayuda

El icono de ayuda permite abrir recursos de soporte:

1. Ver video tutorial: abre la lista de tutoriales en YouTube.
2. Manual de usuario: abre este documento en PDF.

### Menu de usuario

El avatar abre opciones de cuenta:

1. Editar perfil: permite actualizar datos personales disponibles.
2. Acerca de: muestra informacion del sistema cuando la opcion este habilitada.
3. Salir: cierra la sesion actual.

## 4. Inicio

La pagina de inicio es el punto de entrada despues de iniciar sesion. Desde aqui puedes confirmar que tu sesion esta activa y acceder a los modulos disponibles en la barra lateral.

Recomendaciones:

- Revisa que tu nombre y rol sean correctos.
- Si falta un modulo que necesitas, solicita revision de permisos.
- Si el sistema muestra errores de conexion, espera la reconexion o vuelve a iniciar sesion.

## 5. Mis tareas

El modulo Mis tareas organiza el trabajo asignado al usuario. Puede incluir tareas tecnicas, tareas para revisar y tareas administrativas.

### Tareas tecnicas

1. Ingresa a Mis tareas.
2. Selecciona Tecnicas si aparece en tu submenu.
3. Busca la tarea asignada.
4. Abre la tarea para revisar detalle, archivos, comentarios o estado.
5. Actualiza la informacion solicitada segun el flujo de tu area.

Buenas practicas:

- Revisa los archivos adjuntos antes de cambiar el estado.
- Mantén comentarios claros cuando una tarea requiera revision.
- Verifica que el proyecto o etapa seleccionada sea la correcta.

### Tareas para revisar

1. Ingresa a Mis tareas.
2. Selecciona Para revisar.
3. Filtra o ubica la tarea pendiente.
4. Abre el detalle.
5. Aprueba, observa o devuelve segun corresponda.

Antes de aprobar:

- Confirma que los documentos esten completos.
- Revisa que el estado coincida con el avance real.
- Usa observaciones claras si el trabajo requiere correccion.

### Tareas administrativas

1. Ingresa a Mis tareas.
2. Selecciona Administrativas si tienes acceso.
3. Revisa la lista de pendientes.
4. Atiende cada tarea segun las acciones disponibles.

## 6. Tramites

El modulo Tramites centraliza solicitudes, licencias, comunicados, mensajes y pagos. Las opciones visibles dependen del rol.

### Salidas o licencias

1. Ingresa a Tramites.
2. Selecciona Salidas.
3. Revisa la lista de solicitudes o registra una nueva, si tienes permiso.
4. Completa los campos requeridos.
5. Adjunta documentos cuando el formulario lo solicite.
6. Guarda o envia la solicitud.

Para revisar solicitudes:

- Abre el detalle de la solicitud.
- Verifica fechas, motivo y archivos.
- Aprueba, observa o rechaza segun el flujo interno.

### Tramite regular

1. Ingresa a Tramites.
2. Selecciona Tramite regular.
3. Abre el mensaje o expediente que necesitas revisar.
4. Lee el contenido y los adjuntos.
5. Responde, deriva o registra la accion correspondiente.

### Comunicados

1. Ingresa a Tramites.
2. Selecciona Comunicado.
3. Abre el comunicado.
4. Revisa destinatarios, contenido y archivos.
5. Atiende la comunicacion segun tu responsabilidad.

### Tramite de pago

1. Ingresa a Tramites.
2. Selecciona Tramite de pago.
3. Ubica el mensaje o solicitud de pago.
4. Revisa detalle, archivos, montos y estado.
5. Usa las acciones disponibles para responder, reenviar, observar o continuar el proceso.

Notas:

- Algunos flujos generan documentos PDF.
- Si el boton de PDF no responde, revisa que existan datos cargados y que el navegador permita descargas o ventanas emergentes.
- Mantén adjuntos en formato solicitado por el sistema.

### Planilla

La opcion Planilla puede estar restringida a roles especificos.

1. Ingresa a Tramites.
2. Selecciona Planilla si aparece.
3. Revisa la lista de planillas.
4. Abre el detalle para consultar pagos, mensajes o documentos asociados.

## 7. Asistencia

### Registro de asistencia

2. Selecciona Registro.
3. Busca el usuario, fecha o grupo correspondiente.
4. Registra la asistencia segun las opciones del sistema.
5. Guarda los cambios.

### Incidencias

1. Ingresa a Control de asistencia.
2. Selecciona Incidencias.
3. Revisa tardanzas, faltas o registros observados.
4. Filtra por usuario o rango de fechas si el formulario lo permite.
5. Atiende o regulariza segun el proceso interno.

### Reconciliar faltas

1. Ingresa a Control de asistencia.
2. Selecciona Reconciliar faltas.
3. Revisa las faltas detectadas.
4. Marca o corrige los registros cuando corresponda.
5. Guarda los cambios.

## 8. Rotaciones

El modulo Rotaciones gestiona turnos y configuraciones asociadas.

### Mis turnos

1. Ingresa a Rotaciones.
2. Selecciona Mis turnos.
3. Revisa tus turnos programados.
4. Confirma el periodo de responsabilidad, los días comprendidos, el bloque,
   el vencimiento y el estado. En los turnos semanales estos datos corresponden
   al periodo guardado para ese turno y no cambian si luego se edita la actividad.
5. Usa Completar turno para registrar quién realizó la actividad y añadir
   observaciones. Si la realizó otra persona, la observación es obligatoria.
6. Usa Solicitar cambio para elegir entre enviar el turno a la bolsa o
   proponer a otro participante.
7. Si lo envías a la bolsa, únicamente otros participantes elegibles de la
   misma actividad podrán reclamarlo. Si propones a una persona, el turno
   seguirá a tu nombre hasta que la administración apruebe la solicitud.
8. Un turno futuro muestra desde qué fecha se puede completar. Los turnos en
   bolsa o con una propuesta pendiente muestran su estado y evitan acciones
   incompatibles o solicitudes duplicadas.

### Reparacion de asistencia

1. Ingresa a Rotaciones.
2. Selecciona Reparacion de asistencia si tienes acceso.
3. Ubica el registro a corregir.
4. Completa la informacion requerida.
5. Guarda la reparacion.

### Configuracion

La configuracion esta reservada para usuarios con permisos superiores. Si no aparece, no forma parte de tu rol actual.

Las solicitudes de cambio dirigidas aparecen en Cambios dirigidos pendientes.
El administrador debe aprobarlas o rechazarlas; al aprobar, el sistema vuelve a
validar que el destinatario siga siendo participante elegible.

### Basicos

## 18. Recomendaciones generales

- Guarda cambios antes de cambiar de pantalla.
- Verifica que los archivos adjuntos cumplan el formato solicitado.
- Usa filtros para reducir listas grandes.
- No compartas tu usuario ni contrasena.
- Cierra sesion al terminar si usas una computadora compartida.
- Si una accion no aparece, probablemente tu rol no tiene permiso.
- Si el sistema no responde, recarga la pagina y verifica tu conexion.

## 19. Problemas frecuentes

### No veo un modulo

Tu rol puede no tener acceso. Solicita revision al administrador.

### No puedo abrir un PDF

Verifica que el navegador permita ventanas emergentes y descargas. Si el problema continua, informa el modulo y la accion que intentaste ejecutar.

### La informacion no carga

Revisa tu conexion. Si el sistema indica reconexion, espera unos segundos. Si persiste, cierra sesion y vuelve a ingresar.

### Un registro aparece con datos incorrectos

No sobrescribas informacion sin confirmar. Reporta el caso al responsable del modulo o registra una observacion si el flujo lo permite.

## 20. Soporte

Si necesitas ayuda adicional:

1. Revisa primero los video tutoriales.
2. Identifica el modulo, pantalla y accion donde ocurre el problema.
3. Toma nota del mensaje de error si aparece.
4. Comunica el caso al responsable interno o administrador del sistema.
