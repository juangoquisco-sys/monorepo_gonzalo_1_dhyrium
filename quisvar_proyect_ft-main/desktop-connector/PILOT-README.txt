Dhyrium Desktop — Prueba interna

1. Extraiga todo el contenido de este archivo ZIP en una carpeta local.
2. Abra Dhyrium.Desktop.Connector.exe.
3. En “Servidor de Dhyrium”, copie exactamente la dirección mostrada en la
   página “Dhyrium Desktop” de Dhyrium Web.
4. Ingrese con el mismo usuario y contraseña que usa en Dhyrium Web.
5. Pulse “Iniciar sesión”. El programa registra la conexión con su navegador.
6. Vuelva a Dhyrium Web, entre a una tarea y pulse el archivo que desea abrir.

El programa guarda el token de sesión en el almacén seguro de Windows. No guarda
su contraseña. Los archivos se usan en una carpeta administrada de Dhyrium y al
guardar se envían de regreso como una nueva versión.

Esta entrega es una prueba interna para la red de la empresa. Windows puede
mostrar una advertencia porque el instalador firmado de Dhyrium está pendiente.
No continúe si el archivo no fue descargado desde la página oficial de Dhyrium.
